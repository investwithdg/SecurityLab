# Lab setup

**Date:** 2026-08-11
**Topic / Security+ or PenTest+ domain:** N/A — environment setup

## Goal

Get a home lab running to practice for Security+ (and later PenTest+) hands-on.

## What I did

- Installed UTM (free hypervisor for Apple Silicon Macs) via Homebrew: `brew install --cask utm`
- Downloaded the official Kali Linux ARM64 installer from kali.org
- Verified the download against Kali's published SHA256 checksum before using it (never trust a download blindly — this is Security+ material in itself: integrity verification)
- Creating a Kali VM in UTM, set to "Shared Network" mode so it's NATed behind the Mac instead of exposed on the real home network
- Decided against running vulnerable target VMs locally (disk space) — will use TryHackMe/HackTheBox over VPN instead for attack targets

## What happened / what broke

- Ran low on disk space before starting — had to clear caches and remove two abandoned local Supabase Docker projects first
- First checksum check failed — turned out I'd been given the checksum for the wrong Kali file (a similarly-named installer variant), not an actual bad download. Re-pulled the real checksum straight from Kali's server and it matched.

## What I learned

- A "VM" (virtual machine) is just a fake computer running inside a window on the real one — isolated, disposable, safe to break.
- Always verify installer checksums against the vendor's own published values, not a secondhand source.
- Keep vulnerable/target machines off the real home network (NAT/shared network mode, not bridged).
